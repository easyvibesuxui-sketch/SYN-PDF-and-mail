# SYN PDF and mail

Company documents and emails for syniotec's two SaaS products, built on the
[Syn design system](https://github.com/easyvibesuxui-sketch/Syn-Design-System) (its colours, fonts and icons):

- **SAM**: Smart Asset Manager, for construction companies (projects, fleet, employees).
- **RAM**: equipment and service rental.

The backend fills these templates with data and turns them into PDFs and emails.

| Folder | What |
| --- | --- |
| `pdf/` | Report PDFs, as HTML + print CSS |
| `email/` | Email templates (to come) |
